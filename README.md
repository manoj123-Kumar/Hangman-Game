Python Hangman Game | Task 1 - CodeAlpha Python Development Internship.

##  Task Overview
This is Task 1 of my Python Development Internship at **CodeAlpha**. The task is to build a classic Hangman game using Python.

##  About The Game
Hangman is a classic word-guessing game. The player has to guess a hidden word letter by letter. For every wrong guess, a part of the hangman is drawn. The player wins if they guess the word before 6 wrong attempts.

##  Features
- Random word selection from a word list
- Tracks remaining lives (6 attempts)
- Shows correctly guessed letters
- Input validation
- Game Over / You Win messages
- Clean and beginner-friendly Python code

##  Tech Stack
- Language: Python 3
- Concepts Used: Loops, Functions, Random Module, Conditionals, Lists
